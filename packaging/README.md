# 胶卷样张

把一个文件夹里已经按张扫好的 JPG，排成一张 contact sheet，用来发朋友圈、小红书、微信，也可以拿去印刷。

这个包给 64 位 Windows 10 或 Windows 11 使用。不需要另外安装 Python。

## 打开

1. 把整个压缩包解压到一个文件夹。不要只把某一个文件拖出来。
2. 双击「启动胶卷样张.bat」。
3. 第一次打开会慢一些，程序要加载文字识别。

窗口没有出现时，双击「排查启动问题.bat」，把黑窗口里的文字留下来。如果提示缺少 DLL 或 VCRUNTIME，安装微软的 [Visual C++ 2015–2022 x64 运行库](https://learn.microsoft.com/zh-cn/cpp/windows/latest-supported-vc-redist) 后再试。

## 准备照片

一个文件夹就是一卷，也是最后的一张样张。

- 只放这一卷的 `.jpg` 或 `.jpeg`。
- 不要放进子文件夹，程序不会往下找。
- 每张图是一个画格。片边还留在画面里时，序号和胶卷名更容易认出来。

## 窗口

- 左上角「打开文件夹」选择这一卷。
- 读取过程中「取消」会亮起。点下去就停，这次读到的内容不会做成样张。正在读的那一张要等它结束，下一张不会再读。
- 左边是画格列表。可以改边字，也可以拖动调整顺序。
- 中间是预览。
- 右边是规格、胶卷名、订单号、日期、模板和导出。

## 读取时会发生什么

程序先按文件名列出照片，再逐张读取，最后按片边序号从小到大排列。

- 认不出序号的排在最后，并标成「未识别」。
- 序号重复会标成「序号重复」。
- 改过或拖动之后，如果序号没有越来越大，会标成「序号未递增」。
- 太大的图会先缩小再识别，避免读失败。
- 打不开的文件会跳过，列表里显示「无法打开：文件名」。
- 文件夹里一张 JPG 都没有时，提示「这个文件夹里没有 JPG。」

订单号默认是文件夹名字，可以改。日期优先用照片里的拍摄日期，没有就用文件日期。胶卷名会尽量对上预设名单，对不上就保留认到的文字。在右边改完胶卷名、订单号或日期后，要点「应用」，预览才会换成新的内容。

## 规格

可选 135、645、6×6、6×7、6×8、6×9。能判断出来时会自动选上。判断不准时，规格框会标红，预览和导出仍然可用，也可以自己改。

每一行的张数：

- 135：6 张
- 645：4 张
- 6×6：3 张
- 6×7：按 3、3、2、2 循环
- 6×8：3 张
- 6×9：2 张

最后一行不够时，用黑格补满这一行。黑格没有序号。

照片会完整放进格子，不会被裁掉。比例和格子不一致时，多出来的地方是黑边。齿孔只画在每一行的上边和下边。

## 导出

点「导出」，选择保存位置。默认文件名是订单号加上 `.jpg`。订单号为空时，文件名是 `contact-sheet.jpg`。一张可用的照片都没有时，提示「没有可以导出的照片。」

导出如果中途失败，不会覆盖已经存在的同名文件。

三种尺寸都是 4:5，在模板里选择：

- 1080×1350：适合社交平台
- 2160×2700：默认，更清晰
- 2480×3100：接近 A4、300dpi 的印刷尺寸

色彩也在模板里：

- sRGB：发朋友圈、小红书、微信
- CMYK：给印刷。社交软件不一定能正确显示 CMYK

## 样张上的字

右下角最多三行，可以在模板里分别开关：

- 胶卷名
- `Order:` 加上订单号
- 日期、张数，或两者都有，例如 `2026-07-27 | 37 images`

格子下方的黄色数字是片边序号，不是列表里的第几张。品牌字在「设置」里填写，所有模板共用，留空就不印。

## 设置

点「设置」。

- 模板可以新增、复制、重命名、删除，最多 30 个。名字不能重复。「默认」不能删除，也不能改名，其他项目可以改。
- 每个模板可以选择底图、齿孔、色彩、尺寸，以及要不要显示胶卷名、订单号、日期、张数。
- 底图用 JPG 或 PNG。不选就是白底。
- 齿孔用横向可以重复拼接的 PNG。不选就用内置方孔。
- 「打开底图文件夹」「打开齿孔文件夹」可以放进新的图片。「更改底图文件夹」「更改齿孔文件夹」可以换成别的目录。
- 胶卷名预设可以新增、修改、删除。以后识别会用这份名单。

这些内容保存在本机：

`%APPDATA%\FilmContactSheet`

里面有 `backgrounds`、`strips` 和 `settings.json`。换电脑时，把这个文件夹复制过去即可保留模板和预设。
